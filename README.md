# SP Media Works — Bill Generator

Frontend-only React + Vite bill generator.

## Features
- Create PAYMENT BILL
- Mark a bill as PAID and generate PAYMENT RECEIPT
- Live invoice preview
- Automatic subtotal, discount and total
- LocalStorage bill history
- Search and reopen bills
- Download PDF
- Print
- Responsive mobile layout
- SP Media Works black/orange branding

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Notes
- Replace the placeholder UPI field with your real UPI ID.
- Add your preferred QR code to the payment section later.
- Business contact details are intentionally left editable/not hard-coded.
